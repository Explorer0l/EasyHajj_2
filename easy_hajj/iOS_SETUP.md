## 🚀 Шаги для запуска на iOS

### 1. Установите зависимости Flutter

```bash
cd easy_hajj
flutter pub get
```

### 2. Установите CocoaPods зависимости

```bash
cd ios
pod install
```

Если возникнут проблемы, попробуйте:

```bash
pod repo update
pod install --repo-update
```

### 3. Откройте проект в Xcode

```bash
open ios/Runner.xcworkspace
```

**⚠️ ВАЖНО:** Открывайте `.xcworkspace`, а НЕ `.xcodeproj`!

### 4. Настройте подписание (Signing)

В Xcode:
1. Выберите проект **Runner** в навигаторе
2. Перейдите на вкладку **Signing & Capabilities**
3. Выберите свою **Team** (Apple Developer Account)
4. Убедитесь, что **Bundle Identifier** уникален (например: `com.yourname.easyhajj`)

### 5. Проверьте capabilities

Убедитесь, что включены следующие возможности:
- ✅ **Push Notifications** (если планируете использовать)
- ✅ **Background Modes**:
  - Audio, AirPlay, and Picture in Picture
  - Remote notifications
  - Background fetch

### 6. Запустите на реальном устройстве

```bash
flutter run -d <device_id>
```

Или через Xcode: Product → Run (⌘R)

## 🐛 Возможные проблемы и решения

### Проблема: "No such module 'flutter_local_notifications'"

**Решение:**
```bash
cd ios
rm -rf Pods Podfile.lock
pod install
flutter clean
flutter pub get
```

### Проблема: Компас не работает

**Причина:** Симулятор iOS не поддерживает магнитометр.

**Решение:** Тестируйте только на реальном iPhone/iPad.

### Проблема: Уведомления не приходят

**Проверьте:**
1. Разрешения на уведомления в настройках iPhone
2. Настройки → [Ваше приложение] → Уведомления → Разрешить уведомления
3. В коде проверьте, что уведомления включены

### Проблема: "flutter_local_notifications/flutter_local_notifications-Swift.h file not found"

**Решение:**
```bash
cd ios
rm -rf Pods Podfile.lock .symlinks
pod deintegrate
pod install
cd ..
flutter clean
flutter pub get
flutter run
```

### Проблема: Deployment Target ошибка

**Решение:** Убедитесь, что `IPHONEOS_DEPLOYMENT_TARGET = 13.0` во всех конфигурациях.
Это уже настроено в `Podfile`.

## 📱 Сборка для TestFlight / App Store

### 1. Подготовка

```bash
flutter build ios --release
```

### 2. Архив в Xcode

1. Откройте `ios/Runner.xcworkspace` в Xcode
2. Выберите **Generic iOS Device** (не симулятор)
3. Product → Archive
4. После успешной сборки откроется Organizer

### 3. Загрузка в App Store Connect

1. В Organizer выберите свой архив
2. Нажмите **Distribute App**
3. Выберите **App Store Connect**
4. Следуйте инструкциям

- Добавьте скриншоты для iPhone/iPad
- Заполните описание приложения
