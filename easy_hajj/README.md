# EasyHajj - Исламское приложение

Кроссплатформенное мобильное приложение для мусульман с функционалом: времена молитв, Коран, Кибла, Дуа, календарь, мотивация и сообщество.

## 📱 Реализованные экраны (Onboarding)

### 1. Splash Screen
- Логотип EASYHAJJ по центру
- Автоматический переход на Welcome экран через 2 секунды

### 2. Welcome Screen
- Логотип EASYHAJJ
- Кнопка "Пропустить" (верхний правый угол)
- Заголовок "Выберите способ входа"
- 4 кнопки авторизации:
  - Войти с помощью Google
  - Войти с помощью Facebook
  - Использовать номер телефона
  - Войти с помощью почты
- Чекбокс согласия с политикой конфиденциальности

### 3. Location Screen (Геолокация)
- Заголовок "Включить местоположение"
- Иллюстрация с иконкой геолокации
- Блок "Мое местоположение"
- Кнопки:
  - "Мое местоположение" (основная кнопка)
  - "Пропустить" (текстовая кнопка)
- Интеграция с Geolocator для запроса разрешений
- Сохранение координат в SharedPreferences

### 4. Notification Screen (Уведомления)
- Заголовок "Включить уведомления для каждой молитвы"
- Иллюстрация мечети
- Список молитв с переключателями:
  - Фаджр
  - Зухр
  - Аср
  - Магриб
  - Иша
- Кнопки:
  - "Включить уведомления" (основная кнопка)
  - "Пропустить" (текстовая кнопка)
- Интеграция с Flutter Local Notifications

## 🚀 Как запустить

### Предварительные требования
- Flutter SDK установлен
- Android Studio / Xcode для эмуляторов
- Устройство или эмулятор подключен

### Установка и запуск

1. Перейдите в папку проекта:
```bash
cd easy_hajj
```

2. Установите зависимости:
```bash
flutter pub get
```

3. Запустите приложение:
```bash
flutter run
```

### Для Android
```bash
flutter run -d android
```

### Для iOS (требуется macOS)
```bash
flutter run -d ios
```

## 📱 Разрешения

### Android (AndroidManifest.xml)
- `ACCESS_FINE_LOCATION` - точная геолокация
- `ACCESS_COARSE_LOCATION` - приблизительная геолокация
- `POST_NOTIFICATIONS` - уведомления
- `INTERNET` - интернет

### iOS (Info.plist)
- `NSLocationWhenInUseUsageDescription` - геолокация при использовании
- `NSLocationAlwaysUsageDescription` - постоянный доступ к геолокации

## 🔄 Навигация

Поток onboarding экранов:

Каждый экран имеет кнопку "Пропустить" для перехода к следующему экрану.
